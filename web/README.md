# Kimiko Web Dashboard 🏯

A premium Next.js dashboard for the Kimiko AI platform.

## Features
- **💬 Chat**: Real-time conversation with multiple model support.
- **🤖 Agent**: Multi-step reasoning trace and task execution.
- **🧠 Memory**: Explore stored facts and learned user preferences.
- **🔌 Plugins**: View installed plugins and their capabilities.
- **📊 Metrics**: Live system health and service monitoring.

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Configure Environment**:
   Ensure `.env.local` points to your Kimiko API (default: `http://localhost:8000`).

3. **Run in development**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

The dashboard will be available at `http://localhost:3000`.
